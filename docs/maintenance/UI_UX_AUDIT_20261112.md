# Markdown Desk UI and UX audit

This source review follows the screens and actions reachable from the editor, Files, JSON Inspector, Archive Reader, Search, and the external working-copy editor. It uses Pat’s v42 Fold report for the reproduced search and import experience. Changes below are in source. Device layout and accessibility checks remain open.

| Surface and paths reviewed | Finding and disposition |
| --- | --- |
| Editor launch, Files entry, title, open tabs, new document, Write/Read/Split, Focus and lock | The primary editor controls already distinguish modes and editing state. The Files and guide changes give the separate reading workspaces consistent names. Check the editor header, tab strip, and formatting dock at large system text sizes on the cover screen. |
| Editor formatting, undo, outline, command palette, find/replace and document info | Formatting icons have spoken names and shortcuts. The outline and command palette share the filterable picker. Retain their present entry points. Check icon recognition and picker focus in a device pass. |
| Files picker, recent documents, favorites, saved folders, Downloads and all-workspace tabs | The quick Search button formerly opened the single-folder search picker. It now opens the same all-workspace search as the labeled card. The folder-only action remains explicit. File rows can wrap. JSON Inspector, Archive Reader, and Markdown tabs have distinct names. |
| JSON open, tree navigation, scalar reading, page filter, raw search, notes, preview and indexing | The inspector now distinguishes exact text search, JSON path indexing, and complete conversation reading. Conversation exports put Archive Reader first. Pager, annotation and return actions can grow with text. Verify header space and selection on the cover screen. |
| Archive import, library, source handoff, resume, conversation tabs and Back | Completed Inspector imports open the imported file. Alias indexing reuses the source and hides duplicate copies in global listings. Scoped Find backs out to its conversation. Test a multi-conversation file and the older saved-link route independently of the already verified phrase matching. |
| Archive Read/Inspect/Split, message paging, text size, selection, bookmarks, links and export | Read, Inspect, Split and Find are immediately available. A result visit gives Results the same space, with Find still in Tools. Tools groups navigation, notes, output and appearance. Verify that opening Tools retains an active WebView selection for copy, share, print and annotate on Android. |
| Unified Search scope, query, filters, folder scan, result paging and result return | Scope governs which filters are shown and validated. The search box accepts the keyboard Search action. Applied filters are summarized, and the outcome distinguishes counts, no matches and incomplete search. Existing bounded folder scans and explicit rerun after recreation remain. |
| Local document Save, Save as, external-change conflicts, recovery, history and protection | Existing flows distinguish restoring a copy from writing the original. Current wording and confirmation paths were reviewed. Check long provider/file names and dialog actions at enlarged text before making further copy or layout changes. |
| Notes and backlinks across Markdown, JSON and archive, including annotation history | Saved notes and linked sources keep their existing destinations. Archive groups notes and backlinks under Tools. The journal paths and link checks stay intact. A future visual pass can compare the three notebook layouts with populated and empty data. |
| Appearance, themes, reading typography, splash gallery, writing goal and guide | Appearance now says which settings it controls. The guide explains the three JSON and search routes. Theme controls and shared typography remain in place. Check representative light, dark and saturated themes with TalkBack and large text. |
| Markdown sharing, HTML, print/PDF, DOCX and archive exports | The existing file-picker and export completion flows remain. Archive output actions now sit together with clear labels for selected text and complete transcripts. System picker and print-service presentation require device validation. |
| External working-copy editor | The mode action describes its destination, and text-size controls have spoken labels. Existing working-copy review, local draft and return choices remain. Validate the launch and return with an actual host session. |

The next device pass should focus on cover-screen layout, expanded layout, larger system text, TalkBack focus, and selection through Archive Tools. Pat’s previously accepted v42 phrase search does not need to be repeated to establish those UI behaviors.
