# Markdown Desk 2.5.0 — Unified Workspaces

Markdown documents, LLM archives, and general JSON now share one workspace.

## Highlights
- General JSON Inspector with source-bound notes, bookmarks, six highlight colors, backlinks, and Markdown indexes.
- Coherent Claude, linear LLM-message, and ChatGPT graph imports, retaining alternative branches.
- Unified Search with exact passage navigation and return to results.
- Streaming large-file import/reimport, cancellation and restart safeguards, and bounded JSON value paging.
- Improved reading position, selection, tabs, and session restoration.
- Markdown/PDF transcript exports, printing, copying, sharing, and existing editor/DOCX features.
- Existing themes, splash assets, saving, history, and recovery preserved.
