# History, Retention, and Private Backup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task; use checkbox (`- [ ]`) tracking. Owner-delegated conservative choices authorize continued local work without another plan-approval pause. This plan itself changes no runtime behavior.

**Goal:** Add bounded history and private-state recovery without weakening mandatory protected saves or deleting the last recoverable copy.
**Architecture:** First add immutable metadata over existing validated protection handles, with no sensitive save-path changes. Then separately review identity/diff, graph-aware retention, streaming export/import and narrow Activity integration. Recovery records remain authoritative; indexes never authorize deletion.
**Tech Stack:** Existing Java11/JDK17, SDK37.0/build-tools36.0.0, private files, SHA-256, SAF, non-Gradle build; no new dependencies.
**Spec:** [ROADMAP M1](../../ROADMAP.md), [ADR-001](../../decisions/ADR-001-safe-save-boundary.md), [save-protection task4](2026-10-14-save-protection.md), [release gates](../../RELEASE_GATES.md), [CI policy](../../CI_AND_WORKFLOW_POLICY.md), [latest PM instruction](https://github.com/pemunson90-cmd/Markdown-Desk/pull/10#issuecomment-6171465179).

## Global Constraints

- Package `com.example.markdowndesk`, minSdk26/targetSdk35, baseline2.2.5/code18; preserve canonical signing identity, modes, locks,12tabs,9themes and25assets. `android:allowBackup="false"` remains.
- Exact8,388,608-byte document limit including BOM. Preserve UTF-8/BOM/CRLF/whitespace bytes and existing v1 protection, v1 session, v2/legacy recovery readability.
- Ordinary save/Save As/replacement/restore keep the current coordinator and mandatory synchronous protection; history OFF never disables it. No automatic rollback/retry.

## Task3 — Configurable quota and graph-safe retention

**Ownership:** new `HistoryPolicy.java`, `HistoryGraph.java`, `HistoryPruner.java`; narrowly modify `ProtectionStore.java` for common locking, policy and tombstone-aware scans; create `verification/history_retention/{HistoryPrunerCheck.java,PruneRestartProbe.java,run.sh,run_restart.py}`. This is a separate sensitive persistence review, not part of Task1.
**API:** `HistoryPolicy(long quotaBytes,int automaticCount)`; store `setQuotaBytes(long)`, `inspect():Inventory` and package-private `<T> T exclusive(IoOperation<T>)`; `HistoryGraph.scan():Graph`; pruner `planAutomatic(long requiredBytes,int requiredEntries):DeletePlan`, `planSelected(Set<String> checkpointIds):DeletePlan`, `execute(DeletePlan):DeleteResult`, `resume():void`. Inventory contains IDs/types/lengths/hashes/reservations and diagnostics, never payload arrays; graph includes source fingerprint, roots/edges and validated complete groups.
**Policy:** default64MiB, selectable64/128/256/512MiB/1GiB; default20 automatic successful content changes per document, selectable0/5/10/20/50. Zero disables optional retention only. Lower quota below live usage records over-quota state without deleting protected data. Charge catalog/identity metadata and stages, transaction reservations and active pins; coordinate all handles under one root lock. No age timer, deduplication or automatic discard of failed attempts.
**Graph:** retain complete original/attempted pairs as groups. Roots: unresolved transactions, every unowned snapshot/stage, named entries, newest complete pair per document, sole standalone checkpoint, explicit keep records and active export/restore. Edges: completion→preparation→both snapshots, checkpoint→snapshot/group, operation→inputs. Corrupt/unknown/dangling input blocks every deletion. Named dirty snapshots need a durable ownership record; crash before ownership leaves a protected orphan.
**Deletion:** oldest eligible successful groups first; preserve newest complete pair. Explicit selected deletion may remove a named pin/group only with a preview bound to exact graph fingerprint and another validated **local** recoverable group surviving. Unresolved/orphan/sole-local copies remain undeletable in this slice, even after export. Removing a label alone does not delete bytes. No “clear all” action.
**Crash protocol:** max256members/64KiB intent containing exact UUID/type/length/hash and survivor IDs; revalidate graph under lock, commit intent durably, unlink only listed members, sync directories, remove intent only after all members are absent and durability confirmed. Valid pending tombstones explain intermediate missing group members to readers/reservation scans. Replay accepts absent members or exact matching members only; corrupt intent/changed input stops mutation. Replay cannot choose additional files. Separate bounded maintenance allowance1MiB/256entries outside logical history quota funds small intents only, never document payloads; actual ENOSPC still fails before mutation. Reserve/account it explicitly; no unlimited cleanup journal.

- [ ] Implement minimal planner before executor; review graph invariants independently. Run `bash verification/history_retention/run.sh planner`, then executor/fault targets to exit0.

## Task4 — Verified streaming export escape

**Ownership:** new `PrivateArchive.java`, `PrivateExport.java`; create `verification/private_backup/{ArchiveCheck.java,ExportCheck.java,run.sh}`. No change to ordinary save/restore coordinator.
**API:** `PrivateArchive.write(ArchiveSource,OutputStream):ArchiveSummary`, `read(InputStream,EntrySink):ArchiveSummary`; `PrivateExport.exportHistory(Set<String> groupIds,ExportDestination):ExportReceipt`. Source yields repeatable bounded streams; sink receives typed generated IDs, never paths. Destination exposes `identity()`, `read():InputStream`, `write():OutputStream`. Receipt exists only after fresh full readback verifies archive length/hash and inputs.
**Format:** explicit `.mdeskbackup` magic/version, generated entryID/type/length/hash, payload and terminal manifest count/length/digest. No ZIP/compression/extraction paths. Caps:1GiB total,65536entries, snapshot envelope8MiB+32768, metadata64KiB, strings4096UTF-8bytes,64KiB transfer buffer,16MiB metadata-index budget. Reject duplicates, overflow, unknown version/type, truncation and trailing bytes before promotion. No `readAllBytes`, archive-sized array or decompressor.
**Full-quota escape:** pin validated immutable inputs and commit their deterministic manifest in maintenance storage; stream without another snapshot pair. Only newly selected CREATE_DOCUMENT destinations are eligible; reject known source/live/private URIs, null/unreadable/nonempty destinations before writer open. The new export operation protects attempted archive bytes through retained source references+manifest and its observed empty destination through the intent; review this explicit contract against ADR-001 before exposing it. It is not a bypass for document save/restore. The final-check/provider-alias race remains documented. On partial/flush/close/readback error retain local inputs, report incomplete export, no success receipt or automatic deletion. Physical ENOSPC may prevent intent creation and must stop writing.
**Corruption:** diagnostic inventory still exposes errors; no automatic deletion or “successful backup” of invalid records. A separately labeled evidence export may preserve bounded raw invalid files as inert typed attachments; never promote them as valid recovery on import. Valid export pins cannot be released until source retention is independently safe.
