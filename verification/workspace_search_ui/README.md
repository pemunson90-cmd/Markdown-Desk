# Selected saved-root search Activity fixture

Run with installed Java17: `bash verification/workspace_search_ui/run.sh`.

The javac AST extractor inserts unchanged production search fields/classes/helpers,
existing Workspace journey methods, normal open overloads/worker/completions,
dedup/tab capture/restore path and theme helpers. It also inserts the exact native
watcher revision+search invalidation prefix (before suppressed-change return) and
exact mode-route invalidation statement. Android widgets, DocumentIO/provider open
boundary, search broker and hash verifier scheduling are controlled. Normal-open
UI decoration and final viewport scrolling are boundary methods. Existing native
preview/outline suites separately execute the full watcher/navigation machinery.

Results are minted by the REAL WorkspaceLiteralSearch/WorkspaceTreeReader engine
against a controlled resolver, never reconstructed mutable search DTOs. Actual
root registry and real folder broker are used for preflight/nested-browser entry.
104 checks cover:

- Exact selected saved-root scope from a nested browser, literal spaces/Unicode and
 128-unit cap; one preflight slot/callback drop/queued receipt, graceful Activity
 executor shutdown, definite rejection and ambiguous accepted submission.
- COMPLETE/partial/revoked/cancelled/LIMITED-zero, skipped binary types without reads,
 actual100-match cap, and all nine actual query/result/row/notice palette properties.
- Actual normal new open, dirty dedup without reload, tab cap, open failure, stale
 read result, raw BOM/CRLF/emoji match, native dirty/baseline/locks/Split preserved.
- Exact tab/URI/load/revision/route/BOM invalidation, suppressed edits, verifier BUSY
 without supplier/capture/retry, stale callbacks, hash failure and unchanged source.
- One-use own restore/content exemption, second/reentrant setText/restore, thrown
 restore cleanup; source marker never remains across async I/O or exceptions.
- Owned notices, old-dismiss versus replacement, and pause cleanup.

The producer brokers and SearchHitVerifier have separate focused real-worker tests;
this UI fixture records their admission/cancellation/delivery boundaries, not resource
closure or whole-heap disposal. No physical SAF/Android/TalkBack/Fold claim or APK.
The normal reader boundary here is backed by real raw byte fixtures; strict native
UTF8/BOM/read-close behavior remains covered by the unchanged DocumentIO suite.

`SEARCH_UI_SOURCE` / `SEARCH_UI_OUT` optionally select an alternate source/build
folder for focused mutation checks. `run.sh restore` runs only own-restore guards.
A build-only weak-marker mutation failed the reentrant setText check; production
source then passed the full104 checks. No mutation changes production source.
